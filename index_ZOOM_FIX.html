🧠 Quiz — folder-wise practice. Har chapter/topic ke liye alag folder banao, usme apne questions (JSON) upload karo. "🌱 Plant Growth & Development" folder pehle se ban chuka hai purane questions ke saath.
🏆 PYQ Corner — Previous Year Questions, folder-wise. Pehle folder banao (chapter/topic ke naam se), fir usme JSON quiz questions add karo. Timer aur Report Card yahan special gold theme mein milega!
🎓 PW Corner — Subject-wise lectures, PDF notes aur DPP (quiz). Pehle subject chuno, fir chapter folder banao. Video lectures Streamable (ya kisi bhi site) ka link daal ke add karo — video khud upload nahi hota, sirf link save hota hai, storage nahi badhta.

⚡ Physics/Chemistry: chapter ki DPP tab mein questions (JSON) daal do — jaise hi koi lecture "✓ Watched" mark hoga, uss chapter ke DPP bank se 10 random questions (NEET–JEE level) khud-ba-khud quiz mein khul jayenge.
🧩 Module Mania — apne offline coaching module ke questions yahan folder-wise (module-wise) add karo. Pehle module folder banao (jaise "Module 1"), fir usme JSON questions add karo.
